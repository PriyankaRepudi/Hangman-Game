# Hangman Game

A simple console-based Hangman game using Python's `random` module, lists, sets, strings, loops, and conditional statements.

## Requirements
- Python 3.8 or newer
- No external packages

## Run
```bash
python main.py
```

## How to play
1. Run the program.
2. Enter one letter per turn.
3. You can make up to six incorrect guesses.
4. Guess all letters before your incorrect guesses run out to win.

## Concepts used
`random`, lists, sets, strings, `while`, `if/elif/else`, input/output, functions.
